# Rust — catálogo visual da aventura

Cópias dos atlas revisados de `assets/candidates/rust/`, usadas como identidade
visual já existente. `animation.json` contém apenas recortes, pivôs e duração.
Nenhuma hitbox, regra, personagem ou manifesto de combate da luta é carregado.

Procedência original: [produção Rust](../../production/rust/production.json).
A aventura usa sua própria cópia para que ajustes de arte específicos não cruzem
as implementações. Os novos gestos da manhã estão no atlas `rust-morning.png`.
