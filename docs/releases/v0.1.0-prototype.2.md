# Borrow Fighters — correção de imagens e áudio no Windows

A versão **v0.1.0-prototype.2** corrige o carregamento do jogo em pastas com
acentos no Windows, como `Jogos/ação çãõ`. Na primeira versão, isso podia
mostrar lutadores em blocos, cenários só com linhas e deixar o jogo sem áudio,
mesmo com todos os arquivos extraídos.

**Baixe esta atualização se encontrou esse problema.** Use o novo instalador
ou extraia toda a pasta do novo ZIP. O conteúdo do playtest continua o mesmo:
cinco personagens, arenas brasileiras, CPU, duelo local e especiais cinematográficos.
Não precisa instalar Rust nem compilar.

[![Guia de primeira abertura](https://raw.githubusercontent.com/osdeving/borrow-fighters/v0.1.0-prototype.1/docs/evidence/distribution/first-launch.png)](https://github.com/osdeving/borrow-fighters/blob/v0.1.0-prototype.1/docs/evidence/distribution/first-launch.png)

## Qual arquivo baixar

Todos os pacotes são para computadores **x86_64 / 64 bits**.

| Sistema | Download | Como abrir |
|---|---|---|
| Windows 10 (1903+) / 11 | Arquivo terminado em `windows-x86_64-setup.exe` | Execute o instalador e abra Borrow Fighters no menu Iniciar. Instala só para seu usuário. |
| Windows portátil, 10 (1903+) / 11 | Arquivo terminado em `windows-x86_64.zip` | Extraia a pasta inteira e abra `borrow-fighters.exe`. |
| Ubuntu 22.04+ / Debian 12+ e derivados | Arquivo `.deb` | Abra com o instalador de pacotes ou use `sudo apt install ./NOME-DO-ARQUIVO.deb`. |
| Fedora | Arquivo `.rpm` | Abra com o instalador de pacotes ou use `sudo dnf install ./NOME-DO-ARQUIVO.rpm`. |
| Linux portátil | Arquivo terminado em `linux-x86_64.tar.gz` | Extraia a pasta inteira, abra um terminal nela e execute `./borrow-fighters`. |

Baixe os arquivos da seção **Assets** desta release. Os links automáticos
“Source code” são o código para desenvolvedores. Preserve a pasta `assets`
junto do jogo. Windows precisa da versão 10 1903+ ou do Windows 11.
Todos os pacotes precisam de driver com OpenGL 3.3. No Linux, é necessário
desktop com X11 ou XWayland e glibc 2.35+; as bibliotecas incluídas não
substituem o driver de vídeo do computador.

O instalador Windows ainda não é assinado: o Windows pode mostrar editor
desconhecido/SmartScreen. Confira que o download veio deste repositório.
Publicamos `SHA256SUMS.txt` para conferir a integridade dos arquivos.

## Comece por aqui

1. Na primeira abertura, o guia **Como jogar** explica os controles.
2. Escolha jogar contra a CPU, duelo local com outra pessoa ou assistir à demo.
3. Em `Versus Setup`, troque personagens e arena; `Quick Fight` usa a seleção.
4. Tente mover, defender e acertar golpes simples. Depois experimente `T` e `Y`!
5. `R` reinicia a luta; `Esc` volta ao menu. O guia continua disponível no menu.

| Ação | Jogador 1 | Jogador 2 | Controle Xbox |
|---|---|---|---|
| Mover / pular / abaixar | `A D` / `W` / `S` | Setas | Direcional ou analógico / `A` / baixo |
| Defender | `Q` | `U` | `LB` ou `LT` |
| Soco fraco / forte | `F` / `H` | `O` / `P` | `X` / `Y` |
| Chute | `V` | `;` ou `/` | `B` |
| Projétil | `G` | `Ctrl direito` | `RB` |
| Especial | `T` | `\` | `RT` |
| Cinematográfico | `Y` | `]` | Segurar `LB` e apertar `RT` |

O primeiro controle é P1; o segundo é P2. Use **duelo local** para ambos
receberem comandos. Alguns teclados limitam teclas simultâneas; dois controles
podem facilitar jogar junto. Os menus aceitam mouse, setas, Enter e gamepad.

## Ajude com um playtest de 10 minutos

Jogue uma partida com dois personagens diferentes e tente bloquear um especial.
Conta para a gente:

- Deu para instalar e abrir? Qual sistema e placa de vídeo você usou?
- Qual personagem foi mais divertido e qual golpe ficou difícil de entender?
- Teve travamento, áudio ausente, controle que não respondeu ou algo confuso?

[Envie seu feedback ou bug](https://github.com/osdeving/borrow-fighters/issues/new/choose).
Inclua a versão `v0.1.0-prototype.2`, o sistema, passos para reproduzir e,
se puder, uma captura ou vídeo. Feedback curto já ajuda muito. Compartilhe
o link desta release com quem topar testar um jogo de luta com humor de programação!
Se você teve a falha em uma pasta com acentos, conte se as imagens e o áudio
voltaram com esta atualização.

## O que ainda está em construção

- Jogo local, sem multiplayer online; CPU simples e balanceamento experimental.
- Arte, animações e áudio ainda em evolução; Go está fora da seleção pública.
- Supers são fáceis de acionar para testar as animações, sem medidor de energia.
- Janela fixa, sem remapeamento de teclas ou pausa dedicada nesta versão.
- Gravação interna é uma ferramenta opcional que exige FFmpeg; jogar não exige.
- Sprite Viewer/Combat Lab são ferramentas avançadas; uma instalação protegida
  pode impedir salvar edições dos assets pelo viewer.

Os pacotes acompanham `JOGUE-PRIMEIRO.md`, créditos e avisos das bibliotecas.
Instalação e execução automatizadas ficam registradas no workflow da release;
compatibilidade com hardware e controles diferentes depende deste playtest.
